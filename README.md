**The Property Intelligence Platform**

Open-source PropTech platform transforming real estate management through intelligent software architecture, data analytics, and automation.

## 🏗️ Core Products

| Product | Description | Repository |
|---------|-------------|------------|
| **[Prodaric Core](https://github.com/prodaric/Prodaric)** | Foundation platform with APIs, auth, multi-tenancy | Main |
| **[Prodaric Lease](https://github.com/prodaric/Lease)** | Lease lifecycle and contract management | In Development |
| **[Prodaric Invest](https://github.com/prodaric/Invest)** | Investment analysis and ROI calculations | Planned |
| **[Prodaric Market](https://github.com/prodaric/Market)** | Property marketplace for buy/sell/rent | Planned |
| **[Prodaric Manage](https://github.com/prodaric/Manage)** | Property operations and maintenance | Planned |
| **[Prodaric Analytics](https://github.com/prodaric/Analytics)** | Business intelligence and reporting | Planned |

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/prodaric/Prodaric.git
cd Prodaric

# Using Docker (recommended)
docker-compose up -d

# Access the application
open http://localhost:5000
```
